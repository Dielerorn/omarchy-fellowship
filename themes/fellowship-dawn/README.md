# Fellowship Dawn

The light half of [Fellowship](../fellowship/README.md). Same Middle-earth,
read by daylight instead of lamplight.

The ground is the vellum of the Gandalf poster; the ink is the oak-gall brown
of his robe and staff. The accent colours are the same ones the dark theme
uses, darkened until they hold their own against parchment.

| token | hex | where it comes from |
|---|---|---|
| `background` | `#EFDDBB` | vellum |
| `foreground` | `#33291B` | oak-gall ink |
| `accent` | `#9E6F22` | gilt on vellum |
| `red` | `#8E3D2B` | maple ember |
| `orange` | `#A8632A` | autumn beech |
| `green` | `#556B3F` | hedgerow |
| `cyan` | `#3F7168` | verdigris |
| `blue` | `#3E5C77` | the Misty Mountains |
| `magenta` | `#7C4B5C` | dawn on the far peaks |
| `brown` | `#6B4B2F` | Hobbiton oak |

The backgrounds are the same six plates, ordered so this theme opens on the
vellum poster rather than the golden-hour scene, and with Durin's Gate drawn
in ink on paper instead of mithril on dark.

Everything here is generated by `../fellowship/forge/forge.sh` — including
this theme's backgrounds, preview and emblem. See that theme's README for how
the artwork is built and what the Tengwar and futhorc inscriptions say.
